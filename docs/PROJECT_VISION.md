# PROJECT VISION — 0zong ROOM

> 상태: PHASE 0 작성 (2026-10-25). 근거: `0zong_ROOM_Claude_Code_MASTER_PROMPT.md`.

## 한 줄 정의

실제 0zong의 방을 디지털로 복원하고, 방 안의 사물을 눌러 게임·공부·영화·소설·음악·영상·취미 기록으로 들어가는 개인 디지털 세계.

- 방 자체가 홈페이지다.
- 사물이 메뉴다.
- 사물과 상호작용하면 각 콘텐츠 세계로 들어간다.
- 방문자는 열람자이면서 탐험자이고, 일부 콘텐츠에서는 플레이어다.

## 핵심 경험 (우선순위 순)

1. **둘러보기**: 방 전체를 보고 마우스/손가락으로 돌려 본다.
2. **발견하기**: 사물 위에 올리면 반응하고 이름이 보인다.
3. **들어가기**: 사물을 누르면 카메라가 다가가고 그 사물의 콘텐츠가 열린다.
4. **돌아오기**: 언제든 같은 자리의 방으로 돌아온다.
5. **쌓아 가기**: 기록이 계속 추가되고 검색·복습된다 (PHASE 3 이후).

**최초 성공 기준은 화려한 랜딩 페이지가 아니라, 실제로 돌아보고 물체를 선택할 수 있는 방이다.**

## 설계 원칙

| 원칙 | 이 프로젝트에서의 뜻 |
|---|---|
| Reality First | 실제 방의 구조·물건·재질·조명을 우선한다. 사진에 없는 물건을 실제 방처럼 추가하지 않는다. |
| Room as Interface | 메뉴보다 사물을 통한 공간 탐색을 우선한다. 단, 접근성용 대체 경로는 항상 둔다. |
| Interactive Storytelling | 클릭·확대·카메라·사운드를 하나의 흐름으로 잇는다. |
| Personal Knowledge Archive | 기록과 학습 콘텐츠는 계속 입력·검색·복습할 수 있어야 한다. |
| Modular Expansion | 사물/모듈을 추가해도 방 렌더러를 다시 쓰지 않는다. |
| Visual Consistency | 방과 콘텐츠 화면의 분위기가 이어진다. |
| Production Quality | 데모·임시 구현·완성 기능을 구분하고 테스트 증거를 남긴다. |
| Uncertain by Design | 미확정 연출과 구현 방식은 가설로 두고 비교 후 정한다. |

## 하지 않는 것

- 실물 금전 도박, 결제, 환금 (포커는 가상 칩만).
- 방문자 회원가입 강제.
- 방명록 이름으로 특정인의 행동을 자동 연결하는 추적.
- 임시 방을 "실사 복원 완료"로 표시하는 것.
- 영상 프레임만으로 자유 시점 방을 흉내 내는 것 (프레임 연출은 오프닝 전용).
