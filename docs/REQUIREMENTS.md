## 3. 미확정 사항 (결정 필요)

`DECISION_LOG.md`의 "보류" 항목과 같다.

1. 실제 방 복원 방식: 가우시안 스플랫 vs 포토그래메트리 vs 사진 질감 조립 vs 360 사진 — 입력 자료를 받은 뒤 비교.
2. 실측 치수 (현재 손 평면도 추정 2.9×3.8×2.3m).
3. 테트리스 게임 방식 (스프린트/시간 제한/점수전).
4. 체스 특수 규칙 후보 중 무엇을 시험할지.
5. 백엔드 형태 (Next.js 서버 기능 vs 독립 서버), 호스팅.
6. `johnleeyj82-coder/0zong-cinema` 저장소 재사용 여부 — 이 세션에서는 접근 범위 밖이라 **확인하지 못함**.
