# DESIGN SYSTEM

> 상태: PHASE 1 최소 정의. 실제 방 사진과 시간대 조명이 들어오면 다시 맞춘다.

## 정체성

Photorealistic · Cinematic · Personal · Immersive · Atmospheric.
**방 장면이 주인공이고, UI는 사물에 다가갈 때만 나타난다.** 호텔·레스토랑 같은 꾸민 스타일을 강제하지 않고, 실제 방(흰 벽지, 흰 책상, 검은 모니터, 얇은 흰 커튼, 나무 옷장)의 톤을 따른다.

## 색 (src/app/globals.css `:root`)

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--bg` | `#0d0c0b` | 로딩·대체 화면 배경 |
| `--ink` | `#f4efe6` | 본문 글자 |
| `--quiet` | `#b9b1a4` | 보조 글자, 안내 |
| `--glass` | `rgba(18,16,14,.66)` | 떠 있는 버튼·라벨 배경 (+ blur) |
| `--line` | `rgba(255,255,255,.14)` | 테두리 |
| `--accent` | `#ffd27a` | 포커스 링, 상태 배지, 선택된 사물 테두리 |
| 호버 테두리 | `#ffb347` | 3D 사물 호버 |

어두운 유리 UI 하나로 통일했다. 밝은 방 위에서도, 밤 조명에서도 읽힌다.

## 글꼴

`Pretendard, system-ui, Apple SD Gothic Neo, Malgun Gothic`. 웹폰트는 아직 불러오지 않는다(설치된 경우만 사용).
모듈 제목은 영문 대문자(GAME ARCHIVE 등) + 자간 0.03em.

## 구성 요소

| 요소 | 규칙 |
|---|---|
| HUD | 위: 이름, "임시 방 · 실사 복원 전" 배지, 상태 안내. 아래: 사물 바로가기, 방 전체 보기. 화면 가장자리 16px |
| 사물 이름표 | 사물 위 7cm, 이름 + 한 줄 설명. 포인터를 가로채지 않음 |
| 콘텐츠 패널 | 넓은 화면: 오른쪽 `min(460px, 42vw)`. 좁은 화면: 아래 시트 최대 62vh. 맨 위 "← 방으로 돌아가기 ESC" |
| 임시 표시 | 점선 테두리 강조색 배지. 예시 데이터에는 본문 첫 줄에 "예시"라고 적음 |

## 움직임

- 카메라: easeInOutCubic, 0.55~1.3초.
- 패널: 0.35초 슬라이드 + 페이드.
- 장면 밀기: 지수 감쇠(damp 6).
- 모션 감소 설정이면 모두 즉시.

## 사운드 (계획)

카메라 이동·사물 선택에 짧은 효과음, 방 앰비언스. 기본 음소거 해제 금지(첫 상호작용 후에만 재생).
