# 음악 방: 듣기 모드와 미니 플레이어 (설계)

2026-10-29 · 승인: 소유자 (채팅, "음악 방 설계대로 진행해줘")

## 목표

로파이 앱처럼 방을 틀어두고 음악을 듣는다. 주인이 올린 곡을 방문자가 고르고 틀고, 소리·곡 속도·화면 속도·환경음·타이머를
조절한다. 플레이어는 사이트 전체에 하나뿐이라 `/`와 `/movie`를 오가도 끊기지 않는다.

## 범위 밖

방문자의 재생 기록(이벤트 추가), 주인이 환경음 파일을 따로 올리기, 배포용 파일 저장소(나중에 `lib/files.ts`만 교체).

## 서버

- `lib/files.ts` (server-only): 음원 저장·읽기·삭제. 폴더는 `ROOM_MUSIC_DIR` 또는 `data/music`. 파일 앞부분으로 형식 판별
  (mp3: `ID3` 또는 프레임 동기, m4a: `ftyp`, ogg: `OggS`, wav: `RIFF....WAVE`). 확장자·브라우저가 보낸 형식은 믿지 않는다.
- 곡 정보(`Track`)는 `db.json`의 `tracks`: id(uuid), title ≤80, artist ≤60, credit(출처/라이선스) ≤160, duration(초),
  mime, ext, size, addedAt. 목록 순서 = 배열 순서.
- `GET /api/music`: 목록. `POST` (주인, multipart: file, title, artist, credit, duration): 30MB 넘으면 413,
  음원이 아니면 415. `PUT` (주인): 제목·아티스트·출처 고치기. `PATCH` (주인): 순서 `{ order: [id...] }`.
  `DELETE ?id=` (주인): 정보와 파일 함께 삭제.
- `GET /api/music/file/[id]`: id는 uuid만, 저장소에 있는 곡만. `Range` 요청은 206 + `Content-Range`, 아니면 200.
  `Accept-Ranges: bytes`, 한 번 올린 파일은 바뀌지 않으니 오래 캐시.

## 플레이어 (`app/components/music/`)

- `PlayerProvider`를 `app/layout.tsx`에 둔다. `<audio>` 하나 + Web Audio: 곡 → 곡 음량 → 주 음량 → 출력.
  환경음은 파일 없이 생성: 빗소리(흰 소음 → 고역·저역 필터), 모닥불(갈색 소음 + 미리 만든 탁탁 소리 버퍼). 각자 음량.
  오디오는 사용자가 처음 누를 때 시작한다(자동 재생 금지 규칙).
- 상태: 곡 목록, 지금 곡, 재생 여부, 위치/길이, 음량, 곡 속도 0.5~1.5, 음 높이 유지(끄면 테이프처럼),
  환경음 2개 음량, 화면 속도 0~2, 듣기 모드 열림, 잠자기 타이머, 포모도로. 설정과 마지막 곡은 localStorage `room.player`.
- 곡이 끝나면 다음 곡(목록 반복). 이전 버튼은 3초 넘게 들었으면 처음으로, 아니면 이전 곡.
- 잠자기 15/30/60분: 마지막 30초 동안 주 음량을 0으로 내리고 멈춘 뒤 음량을 되돌린다.
  포모도로 25분 집중 / 5분 휴식 반복: 바뀔 때 짧은 종소리(오실레이터), 남은 시간 표시.
- 페이지 사이 링크는 데모가 아니면 `next/link`(플레이어 유지), 데모는 지금처럼 `index.html` 링크.

## 화면

- **미니 플레이어**: 왼쪽 아래 유리 알약. 재생/일시정지, 제목, 진행 막대, 듣기 모드. 한 번이라도 재생하거나 환경음을 켜면
  나타난다. 768px 미만은 독 위.
- **듣기 모드**: 방 전경(마지막 프레임)이 화면 가득. 캔버스 빗줄기, 램프가 숨 쉬듯 밝아짐, 아주 느린 카메라 이동.
  셋 다 화면 속도를 따른다(0이면 멈춤). `prefers-reduced-motion`이면 저장된 값이 없을 때 화면 속도 0으로 시작.
  아래 조작부: 제목·아티스트·출처, 이전/재생/다음, 진행 막대(이동 가능), 음량, 곡 속도와 음 높이, 화면 속도,
  빗소리·모닥불, 타이머. 3초 동안 움직임이 없으면 조작부가 흐려진다. Esc로 닫기, 전체 화면 버튼.
- **음악 서랍**: 지금 곡, 곡 목록(누르면 재생), "듣기 모드로 들어가기". 주인: 올리기(제목·아티스트·출처, 길이는 자동),
  고치기, 위/아래로 순서, 지우기(두 번). 올리기 화면에 "직접 만든 곡이나 공개해도 되는 라이선스의 곡만" 안내.
  곡이 없으면 "아직 올린 곡이 없어요. 빗소리만 틀어두고 쉬어가도 돼요."
- 데모: 곡 올리기 없음(안내), 환경음과 듣기 모드는 동작.

## 검증

curl: 업로드(주인 아님 403, 31MB 413, 음원 아님 415, 정상 200), Range 206, 고치기·순서·삭제. Playwright: 올리기 → 재생 →
`/movie`로 이동 후에도 재생 중, 음량·속도·음 높이가 `<audio>`에 반영, 환경음 켜짐, 잠자기 타이머 종료, 듣기 모드 열고 닫기,
데스크톱·모바일 스크린샷. `tsc`, `build`, `export-preview`.
