# 3D 방: 스크롤 투어를 3D 디오라마로 (설계)

2026-10-29 · 승인: 소유자 (채팅, 설계안 "응 좋은데" + 취미별 물건 연결 확인)

## 목표

`/`의 스크롤 투어를 **내 방 3D 디오라마**로 바꾼다. 방 안의 물건 하나하나가 취미이고, 누르면 지금의 캡션 카드·서랍·
페이지로 이어진다. 서울의 실제 시간·날씨, 내 PC의 앱 감지(Windows), 가끔 일어나는 이벤트가 방을 살아 있게 한다.
주인(나)은 기록하고 틀어두는 공간으로, 구경꾼은 구경하는 공간으로 쓴다. apochill-kit은 아이디어만 참고하고 코드·에셋은
쓰지 않는다.

## 결정 사항 (질문으로 정함)

| 항목 | 결정 |
|---|---|
| 3D 방 | 방 껍데기(벽·바닥·창·커튼·선반)는 코드로, 가구는 Tripo GLB. 그 전까지는 대체 모양 |
| 사용자 | 주인 = 지금의 주인 모드(서명 쿠키). 구경꾼 = 구경만. 방문자 계정은 만들지 않음 |
| "지금 뭐 하나" | 기록 구경("오늘의 방") 중심. 실시간 말풍선은 주인이 켰을 때만, 분류 단위 |
| 시간·날씨 | 서울 실제 시간 + Open-Meteo 서울 날씨(30분 캐시). 주인은 틀어둘 때 날씨를 고를 수 있음 |
| 앱 감지 | Windows 도우미, 도우미 전용 토큰 |
| 엔진 | react-three-fiber + drei (Next.js 안, `/`에서만 불러옴) |

## 1. 화면 구조

- `app/page.tsx`: 히어로 자리에 `RoomScene`(R3F Canvas, `ssr:false` 동적 로딩). 그 위에 지금의 독, 캡션 카드, 서랍,
  미니 플레이어, 듣기 모드, 오프닝, 방명록이 그대로 얹힌다. 아래 섹션(소개·방들·최근·방명록)은 유지(스크롤 가능).
- 장면 정의(`app/scene/rooms/my-room.ts`): 방 크기, 껍데기 부품, 물건 목록
  `{ key(RoomKey), model?: "/models/room/<key>.glb", placeholder, position, rotation, scale, focus: 카메라 위치·바라볼 점 }`,
  램프(점광원 위치·색), 창(영역·밖 풍경), 기본 카메라. 방을 더 만들 때 정의 하나를 추가한다.
- 스크롤 투어(ScrollHero, 202프레임 22MB)는 1단계가 끝나 장면이 대신할 수 있을 때 제거한다.

## 2. 취미 = 물건

| 취미 | 물건 | | 취미 | 물건 |
|---|---|---|---|---|
| music | 턴테이블 | | poker | 포커 테이블 |
| video | 프로젝터 | | art | 이젤 |
| book | 책장 | | whisky(바) | 위스키 선반 |
| game | 듀얼 모니터 왼쪽 | | chess | 체스판 |
| hack | 듀얼 모니터 오른쪽(터미널) | | movie | 프로젝터 스크린 |
| tetris | 책상 위 작은 게임기(새로 놓음) | | | |

- 고르기: 마우스를 올리면 살짝 빛남(램프 프레임 색). 누르거나 독 아이콘을 누르면 카메라가 그 물건의 `focus`로 천천히
  이동하고 캡션 카드(제목·소개·최근 소식·"열어보기")가 뜬다. "열어보기" → 지금의 서랍(영화·게임은 페이지로 이어짐).
- 방 둘러보기: 물건 순서대로 카메라 자동 투어(← →로도). 독의 진행 막대 = 둘러본 물건 수 / 11.
- 기록: `view`(캡션 1.2초), `dock`, `open` 이벤트는 지금과 같다.
- 빈 곳을 끌면 정해진 범위 안에서 둘러보기(OrbitControls 제한), Esc나 빈 곳 클릭은 전체 시점으로.

## 3. 내 방 만들기 (에셋)

- 껍데기: 렌더(`frame_0202`) 배치를 따라 코드로. 창 밖은 도시 불빛 평면 + 비.
- 대체 모양: 물건마다 단순한 형태(상자·원통)와 렌더에서 뽑은 대표색. GLB가 생기면 같은 자리에 교체(크기 맞춤은 정의의 scale).
- `npm run models`: `public/models/room/src/*.glb` → Draco 압축, 텍스처 1024px webp → `public/models/room/*.glb`.
- Tripo 입력 그림: 렌더에서 물건을 잘라 Runway(이미지 모델)로 흰 배경·3/4 각도로 다시 그림. 생성은 주인이 Tripo에서.

## 4. 시간·날씨

- `GET /api/env`: Open-Meteo(서울 37.5665, 126.978) 현재 날씨 코드·기온·일출·일몰, 30분 캐시. 실패하면 맑음.
  주인 설정(`settings.envOverride`: auto/clear/cloudy/rain/storm/snow)이 있으면 그것.
- 장면: 서울 시각(Asia/Seoul)으로 하늘·햇빛 방향·환경광, 램프는 해 진 뒤 밝아짐, 창밖 도시 불빛은 밤에. 비·폭우는
  창 안 빗줄기 + 번개(폭우), 눈은 눈송이. 날씨에 맞춰 음악 엔진의 빗소리를 제안(자동으로 켜지는 않음).

## 5. 캐릭터·말풍선·이벤트 (3단계)

- 책상의 캐릭터(대체 모양 → Tripo). 말풍선(HTML, 3D 위치에 붙음): 공개를 켰을 때 실시간 분류 → Steam 지금 하는 게임 →
  시간대별 평소 대사.
- 이벤트: 3~8분마다 하나, 시간·날씨 조건에 맞는 것(고양이, 별똥별, 비가 그침, 노크). 모션 줄이기면 끔.

## 6. 앱 감지와 오늘의 방 (2단계)

- Windows 도우미 `tools/0zong-helper.ps1`(설치 없음): 30초마다 앞 창의 프로세스 이름 → 허용 목록 → 분류
  (코딩·게임·디자인·공부·영상·쉬는 중). 창 제목·문서 내용은 읽지도 보내지도 않음.
- `POST /api/activity` (도우미 토큰, Bearer): `{ category, app }`. 토큰은 주인 화면에서 만들고 한 번만 보여줌, 서버에는
  해시만. 끊기·새로 만들기 가능.
- 저장: 현재 상태(2분 지나면 없음) + 날짜×분류 분 단위 합계. 앱 이름은 주인만, 공개는 분류만.
- 오늘의 방(구경꾼): 오늘과 최근 7일 분류별 시간 + Steam 플레이 + 영화 기록 + 게임 메모 + 올린 곡 타임라인.
- 실시간 공개: 기본 꺼짐, 켜면 말풍선에 분류만, 몇 분 늦게.

## 7. 주인과 구경꾼

같은 방. 주인: 포모도로·타이머·기록 버튼·도우미 연결·날씨 고르기가 보인다. 구경꾼: 오늘의 방·방명록.

## 8. 무게·접근성

- 3D는 `/`에서만 동적 로딩, 첫 로딩 목표 15MB 이하, 진행률 표시. 화질 상/중/하(그림자·해상도), 기기 보고 자동 선택.
- WebGL이 없거나 너무 느리면 방 정지 이미지 + 지금의 2D 화면으로 대신.
- 키보드: 독과 Tab으로 모든 물건에 갈 수 있고(숨은 버튼 목록), 캡션 카드는 aria-live. 모션 줄이기면 카메라 이동은 즉시.

## 단계

1. 장면 엔진 + 방 껍데기 + 대체 가구 11개 + 고르기·캡션·서랍 + 독 연결 + 둘러보기 + 서울 시간·날씨 + 화질·대체 화면.
   (Tripo 없이)
2. Windows 도우미 + 토큰 + 실시간 말풍선 + 오늘의 방.
3. Tripo 가구 교체 + `npm run models` + 캐릭터 + 이벤트. (Tripo 유료)
4. 두 번째 방 + 주인 배치 모드.

## 검증 (각 단계)

`tsc`, `build`, Playwright(WebGL 소프트웨어 렌더): 물건 클릭 → 캡션 → 서랍, 독 → 카메라 이동, 둘러보기, 날씨 흉내 서버로
비·눈·밤 화면, 대체 화면. 데스크톱·모바일 스크린샷. 3D 첫 로딩 용량 측정.
