## 목표

`/`를 **내 방 3D 디오라마** 한 화면으로 바꾼다(스크롤 없음). 방 안의 물건 하나하나가 취미이고, 누르면 캡션 카드·서랍·
페이지로 이어진다. 실내라서 **방 문**이 있고, 문으로 다른 방에 들어갈 수 있다. 서울의 실제 시간·날씨, 내 PC의 앱 감지(Windows), 가끔 일어나는 이벤트가 방을 살아 있게 한다.
주인(나)은 기록하고 틀어두는 공간으로, 구경꾼은 구경하는 공간으로 쓴다. apochill-kit은 아이디어만 참고하고 코드·에셋은
쓰지 않는다.

## 결정 사항 (질문으로 정함)

| 항목 | 결정 |
|---|---|
| 3D 방 | 방 껍데기(벽·바닥·창·커튼·선반)는 코드로, 가구는 Tripo GLB. 그 전까지는 대체 모양 |
| 사용자 | 주인 = 지금의 주인 모드(서명 쿠키). 구경꾼 = 구경만. 방문자 계정은 만들지 않음 |
| "지금 뭐 하나" | 기록 구경("오늘의 방") 중심. 실시간 말풍선은 주인이 켰을 때만, 분류 단위 |
| 시간·날씨 | 서울 실제 시간 + Open-Meteo 서울 날씨(30분 캐시). 주인은 틀어둘 때 날씨를 고를 수 있음 |
| 앱 감지 | Windows 도우미, 도우미 전용 토큰 |
| 엔진 | react-three-fiber + drei (Next.js 안, `/`에서만 불러옴) |

## 1. 화면 구조

- **스크롤 개념은 쓰지 않는다.** `/`는 화면 전체가 3D 방인 한 화면이다(apochill처럼 페이지 스크롤 없음).
  지금의 스크롤 투어(ScrollHero, 202프레임 22MB)와 그 아래 섹션(소개·방들 격자·최근·방명록·마무리)은 이 화면에서 뺀다.
  방명록·소개·최근 소식은 독에서 여는 패널로 옮긴다.
- `app/page.tsx`: `RoomScene`(R3F Canvas, `ssr:false` 동적 로딩) + 그 위의 UI(독, 캡션 카드, 서랍, 패널, 미니 플레이어,
  듣기 모드, 오프닝).
- 카메라: 마우스로 끌어서 방을 둘러보기(정해진 범위 안에서 회전·확대, OrbitControls 제한). 물건을 골라도 카메라가
  그 물건으로 날아가지 않는다(나중에 추가할 수 있게 장면 정의에 `focus` 자리만 비워 둔다). 물건 투어(자동 순회)는 없다.

### 방과 문 (실내 구조)

세 방이고, 메인 방이 가운데다. 처음 들어오면 메인 방(`/` = `/?room=main`).

```
 영화방 ──문── 메인 방 ──문── 침실
(cinema)       (main)       (bedroom)
```

- **방 정의**(`app/scene/spaces/<id>.ts`): 방 크기, 껍데기 부품, 물건 목록
  `{ key, model?: "/models/<room>/<key>.glb", placeholder, position, rotation, scale }`, 램프, 창, 기본 카메라,
  **문 목록** `{ id, to: 다른 방 id, position, rotation, label }`.
- **문**: 물건처럼 마우스를 올리면 빛나고 이름표("영화방으로" 등), 누르면 짧은 암전(약 0.6초) 뒤 그 방으로 바뀐다.
  바뀐 방에서는 들어온 문 쪽에서 시작한다. 방마다 모델은 그 방에 들어갈 때 불러오고, 옆방은 쉬는 시간에 미리 불러온다.
- 지금 있는 방은 주소에 남긴다(`/?room=<id>`), 새로고침해도 그 방. 왼쪽 위 막대에 방 탭(영화방 · 메인 방 · 침실)과
  서울 시각·날씨. (구현하며 독에서 왼쪽 위로 옮김: 독은 취미만으로도 꽉 참)
- 방이 바뀌어도 음악 플레이어·서랍 상태는 그대로(같은 페이지 안).

## 2. 취미 = 물건 (방별)

| 방 | 물건 → 취미 |
|---|---|
| **메인 방** | 듀얼 모니터 왼쪽 → game · 듀얼 모니터 오른쪽(터미널) → hack(보안 공부) · 책장 → book(소설 기록) · 이젤 → art · **전시대** 위 체스판 → chess, 작은 게임기 → tetris |
| **영화방** | 프로젝터 → video · 스크린 → movie · 턴테이블(LP) → music · 위스키 선반 → whisky(바) · 포커 테이블 → poker · 소파(앉을 자리, 취미 없음) |
| **침실** | 침대 → **방의 시간 바꾸기**(아래) · 창 · 협탁 램프 |

- 메인 방의 전시대는 미니게임(체스·테트리스)을 박물관 진열처럼 놓는 받침대. 3단계에서 실제로 하는 게임이 붙어도 같은 자리.
- 고르기: 마우스를 올리면 살짝 빛남(램프 프레임 색) + 이름표. 누르면 캡션 카드(제목·소개·최근 소식·"열어보기")가
  화면 한쪽에 뜬다(카메라는 그대로). "열어보기" → 지금의 서랍(영화·게임은 페이지로 이어짐).
- 독: 취미 아이콘을 누르면 그 물건의 캡션 카드가 뜨고 물건이 빛난다. 그 물건이 다른 방에 있으면 그 방으로 먼저 옮긴다.
  독은 방별로 묶어서 보여준다. 투어 진행 막대는 없앤다.
- 기록: `view`(캡션 카드가 1.2초 보이면), `dock`, `open` 이벤트는 지금과 같다. 방 이동은 `move` 이벤트(`room`에 방 id만).
- 빈 곳 클릭이나 Esc는 캡션 카드를 닫는다.

### 침대: 방의 시간 바꾸기

- 침대를 누르면 시간 고르기: **새벽 · 아침 · 낮 · 노을 · 밤 · 지금(서울 실제 시간)**. 고르면 짧게 눈 감았다 뜨는 암전 뒤
  모든 방의 하늘·햇빛·램프·창밖이 그 시간으로 바뀐다.
- 보는 사람 화면에서만 바뀐다(서버에 저장하지 않음, 그 탭에서만 유지). 다른 사람에게는 여전히 서울 실제 시간.
- 시간을 바꾼 동안 왼쪽 위 막대에 작은 표시("밤으로 맞춤 · 지금으로")가 있어 언제든 실제 시간으로 돌아간다.
- 날씨는 그대로 실제(또는 주인이 고른 날씨). 주인의 날씨 고르기(§4)는 모두에게, 침대 시간은 나에게만.

## 3. 방 만들기 (에셋)

- 참고 그림: 기존 방 이미지(한 방에 모든 취미)를 **변형**해서 세 방 그림을 만든다. 메인 방은 기존 그림에서 영화·바·포커
  쪽을 빼고 전시대를 넣은 것, 영화방·침실은 같은 화풍·조명으로 새로 그린 것(Runway 이미지 모델, 기존 그림을 참고 이미지로).
  이 그림들은 배치·색을 정하는 참고용이고 사이트에 직접 보이지 않는다(대체 화면의 정지 이미지로만 씀).
- 껍데기: 참고 그림 배치를 따라 코드로. 창 밖은 도시 불빛 평면 + 비.
- 대체 모양: 물건마다 단순한 형태(상자·원통)와 렌더에서 뽑은 대표색. GLB가 생기면 같은 자리에 교체(크기 맞춤은 정의의 scale).
- `npm run models`: `public/models/<room>/src/*.glb` → Draco 압축, 텍스처 1024px webp → `public/models/<room>/*.glb`.
- Tripo 입력 그림: 렌더에서 물건을 잘라 Runway(이미지 모델)로 흰 배경·3/4 각도로 다시 그림. 생성은 주인이 Tripo에서.

## 4. 시간·날씨

- `GET /api/env`: Open-Meteo(서울 37.5665, 126.978) 현재 날씨 코드·기온·일출·일몰, 30분 캐시. 실패하면 맑음.
  주인 설정(`settings.envOverride`: auto/clear/cloudy/rain/storm/snow)이 있으면 그것.
- 장면: 서울 시각(Asia/Seoul)으로 하늘·햇빛 방향·환경광, 램프는 해 진 뒤 밝아짐, 창밖 도시 불빛은 밤에. 비·폭우는
  창 안 빗줄기 + 번개(폭우), 눈은 눈송이. 날씨에 맞춰 음악 엔진의 빗소리를 제안(자동으로 켜지는 않음).

## 5. 캐릭터·말풍선·이벤트 (3단계)

- 메인 방 책상의 캐릭터(대체 모양 → Tripo). 말풍선(HTML, 3D 위치에 붙음): 공개를 켰을 때 실시간 분류 → Steam 지금 하는 게임 →
  시간대별 평소 대사.
- 이벤트: 3~8분마다 하나, 시간·날씨 조건에 맞는 것(고양이, 별똥별, 비가 그침, 노크). 모션 줄이기면 끔.

## 6. 앱 감지와 오늘의 방 (2단계)

- Windows 도우미 `public/tools/0zong-helper.ps1`(설치 없음, 주인 화면에서 받기): 30초마다 앞 창의 프로세스 이름 → 허용 목록 → 분류
  (코딩·게임·디자인·공부·영상·쉬는 중). 창 제목·문서 내용은 읽지도 보내지도 않음.
- `POST /api/activity` (도우미 토큰, Bearer): `{ category, app }`. 토큰은 주인 화면에서 만들고 한 번만 보여줌, 서버에는
  해시만. 끊기·새로 만들기 가능.
- 저장: 현재 상태(2분 지나면 없음) + 날짜×분류 분 단위 합계. 앱 이름은 주인만, 공개는 분류만.
- 오늘의 방(구경꾼): 오늘과 최근 7일 분류별 시간 + Steam 플레이 + 영화 기록 + 게임 메모 + 올린 곡 타임라인.
- 실시간 공개: 기본 꺼짐, 켜면 말풍선에 분류만, 몇 분 늦게.

## 7. 주인과 구경꾼

같은 방. 주인: 포모도로·타이머·기록 버튼·도우미 연결·날씨 고르기가 보인다. 구경꾼: 오늘의 방·방명록.

## 8. 무게·접근성

- 3D는 `/`에서만 동적 로딩, 첫 로딩 목표 15MB 이하, 진행률 표시. 화질 상/중/하(그림자·해상도), 기기 보고 자동 선택.
- WebGL이 없거나 너무 느리면 방 정지 이미지 + 지금의 2D 화면으로 대신.
- 키보드: 독과 Tab으로 모든 물건에 갈 수 있고(숨은 버튼 목록), 캡션 카드는 aria-live. 모션 줄이기면 카메라 이동은 즉시.

## 단계

1. 장면 엔진 + **세 방 껍데기**(메인·영화·침실) + 대체 가구(취미 11개 + 소파·전시대·침대) + 고르기·캡션·서랍 + 독 연결 +
   문과 방 이동 + **침대 시간 바꾸기** + 스크롤 투어와 아래 섹션 제거(방명록·소개·최근은 패널로) + 서울 시간·날씨 +
   화질·대체 화면. (Tripo 없이)
2. Windows 도우미 + 토큰 + 실시간 말풍선 + 오늘의 방.
3. Tripo 가구 교체 + `npm run models` + 캐릭터 + 이벤트. (Tripo 유료)
4. 세 방 참고 그림을 Runway로 만들고 소품 채우기 + 주인 배치 모드 + (원하면) 물건으로 카메라 이동 연출.

## 검증 (각 단계)

`tsc`, `build`, Playwright(WebGL 소프트웨어 렌더): 물건 클릭 → 캡션 → 서랍, 독 → 캡션, 문 → 방 이동(주소 유지), 다른 방 물건의 독 아이콘 → 방 이동 + 캡션, 침대 → 시간 바뀜·지금으로 복귀,
날씨 흉내 서버로 비·눈·밤 화면, 대체 화면, 페이지가 스크롤되지 않음. 데스크톱·모바일 스크린샷. 3D 첫 로딩 용량 측정.
