# 3단계 계획: 진짜 가구 모델로 방 구성하기

2026-11-02 · 상태: 계획 (소유자 확인 전). 상위 설계: `2026-10-29-3d-room-design.md` §3·§5.

지금의 대체 모양(상자·원통)을 같은 자리·같은 크기의 GLB 모델로 바꾸고, 메인 방 책상에 캐릭터를 앉힌다.
**장면 코드는 고치지 않는다.** 물건 정의에 `model`만 채우면 바뀐다(불변 조건).

## 1. 원칙

1. **자리와 크기는 지금 것이 기준이다.** 1단계에서 이미 동선·카메라 시야·클릭 영역을 맞춰 뒀다. 모델은 그 상자 안에 들어간다.
2. **한 화풍.** 11개 취미 물건과 큰 가구가 한 사람이 만든 것처럼 보여야 한다.
   - 화풍: **따뜻한 스타일라이즈드(반실사)**. 모서리는 살짝 둥글고, 무광, 텍스처는 단순하다.
   - 사실적 스캔 느낌과 장난감 같은 로우폴리는 모두 피한다.
   - 이유: 장면(Stage)들이 이미 일러스트·타이포 중심이라 방도 "그림 같은 실내"여야 어울리고, AI 3D 생성은 반실사에서 가장 덜 깨진다.
3. **색은 방이 정하고, 물건은 따른다.** 방마다 팔레트가 있다(§4). 모델 텍스처가 튀면 정리 단계에서 색을 낮춘다.
4. **화면 앞쪽은 낮게.** 카메라가 앞(+z) 위에서 내려다보므로, 방 앞쪽 1.5m 안의 물건은 0.6m 이하로 둔다. 키 큰 물건(1.8m 이상)은 옆벽에만 둔다. 창 앞 물건은 1.2m 이하로 둬서 창밖이 가려지지 않게 한다.
5. **통로.** 문 앞 0.9×0.9m와 주 동선 폭 0.8m는 비워 둔다.

## 2. 단위와 모델 규칙

| 항목 | 규칙 |
|---|---|
| 단위 | 1 = 1m, Y가 위 |
| 원점 | 물건 바닥면의 가운데 (바닥에 놓으면 y=0) |
| 정면 | +Z를 본다. 벽에 붙는 물건은 정의의 `rotY`로 돌린다 |
| 취미 물건 (11개) | 삼각형 15k 이하, 텍스처 1024px 1장 |
| 큰 가구 (소파·침대·책상 등) | 삼각형 10k 이하, 텍스처 1024px |
| 소품 | 3k 이하, 512px. 대부분 지금의 코드 소품을 유지 |
| 방 하나 합계 | 삼각형 15만 이하, GLB 합계 5MB 이하 (Draco + webp 압축 후) |
| 재질 | PBR 1개(베이스컬러 + 거칠기). 금속성은 손잡이·턴테이블처럼 필요한 곳만. 빛나는 부분(모니터·스크린·전구)은 emissive 맵으로 분리 |

크기는 사람이 맞추지 않는다. `npm run models`가 매니페스트(§6)의 목표 크기에 맞춰 자동으로 축소·확대하고 원점을 잡는다.

## 4. 방별 구성과 분위기

### 메인 방: "일하고 만드는 방"

```
            뒷벽 (창 2.6m)
  ┌──────────────────────────────────────┐
  │ 책장      화분 [  책  상  ]  캔버스   │
  │ (book)        [게임][보안]  이젤(art) │
  │                   의자    물감카트    │
  │ 스탠드                               전시대│
  문               ( 러 그 )            (체스 │
  (영화방)                               테트리스)│
  │  빈백   책더미                         문│
  │                                (침실) │
  └──────────────────────────────────────┘
              ↑ 카메라 (앞쪽은 낮게)
```

- 구역: 뒤 가운데 **작업**(책상·모니터), 왼쪽 **기록**(책장), 오른쪽 뒤 **창작**(이젤·물감), 오른쪽 벽 **전시**(미니게임), 앞 왼쪽 **쉬는 곳**(빈백).
- 팔레트: 벽 따뜻한 갈색 `#4a3a2e`, 바닥 월넛, 포인트 텅스텐 `#e9b872`, 러그 와인색.
- 조명: 책상 스탠드(주광원), 장 스탠드, 전시대 스포트, 벽 전구 줄. 밤에는 모니터 빛이 책상을 비춘다.

## 5. 참고 그림과 모델 만들기

1. **참고 그림** (물건 하나당 1장)
   - 기존 방 이미지에서 물건을 잘라 이미지 모델로 다시 그린다. 흰 배경, 3/4 각도, 그림자 없음, 화풍 문장 고정.
   - 화풍 문장: "warm stylized semi-realistic, matte, soft rounded edges, simple textures, cozy night room prop".
   - 같은 문장과 같은 시드를 계속 쓴다.
2. **3D 생성**
   - Tripo의 이미지→3D(텍스처 포함)로 만든다.
   - 이 세션에서 쓸 수 있는 다른 이미지→GLB 도구(Higgsfield `generate_3d`)는 같은 물건으로 품질과 비용을 비교한 뒤 고른다.
3. **정리** (`npm run models`, §6): 크기 맞춤, 원점, 압축.
4. **확인**: 방에 넣고 낮과 밤 화면을 찍어, 취미 물건이 한눈에 구분되는지와 빛나는 부분을 본다.

### 순서와 예산 (Tripo 무료 200크레딧 기준, 1개당 비용은 확인 필요)

| 묶음 | 물건 | 개수 |
|---|---|---|
| 3a | 취미 물건 11개 (모니터 2개는 모델 하나를 같이 씀, 스크린은 코드로 유지 가능) | 9~10 |
| 3b | 큰 가구: 책상+의자, 소파, 침대, 포커 의자, 옷장, 빈백, 전시대 | 7 |
| 3c | 캐릭터 1 (§7) | 1 |
| 유지 | 전구 줄, 러그, 액자, 책 더미, 머그 같은 소품 (코드 모양이 오히려 깔끔함) | 0 |

- 생성 1회가 크레딧을 얼마나 쓰는지 먼저 1개로 확인하고, 모자라면 3b를 유료로 돌리거나 일부는 코드 모양으로 남긴다.
- 무료 플랜 결과물은 공개·비상업 조건일 가능성이 높다. 사이트가 공개되기 전에 Tripo 이용 조건을 확인한다.

## 6. `npm run models` (정리 스크립트)

`public/models/src/<room>/<key>.glb`(생성 원본) → `public/models/<room>/<key>.glb`(사이트용).

매니페스트 `app/scene/models.json`의 한 줄:

```json
{ "room": "main", "key": "easel", "size": [0.7, 0.6, 1.75], "fit": "height", "emissive": [] }
```

처리 순서 (gltf-transform):

1. 바운딩 박스를 재서 `fit` 기준(높이·폭·가장 긴 변)으로 목표 크기에 맞게 균일 확대·축소한다.
2. 원점을 바닥 가운데로 옮기고, 정면을 +Z로 맞춘다(필요하면 매니페스트의 `rotY`).
3. 중복 정점 병합, 삼각형이 예산을 넘으면 단순화한다(meshopt).
4. 텍스처는 1024/512px webp로, 지오메트리는 Draco로 압축한다.
5. 결과 크기를 표로 출력하고, 방 예산(5MB)을 넘으면 실패시킨다.

그다음 물건 정의에 `model: "/models/main/easel.glb"`만 넣는다. 장면은 모델이 오기 전까지 대체 모양을 보여주고(물건마다 Suspense), 실패하면 대체 모양을 유지한다.

## 7. 캐릭터 (3c)

- **모습**: 방 주인을 닮은 2~2.5등신 스타일라이즈드 인물. 앉은 키 약 1.1m, 서면 약 1.4m(가구보다 살짝 작아서 디오라마 인형처럼 보임). 후드티와 슬리퍼, 방 팔레트 안의 색.
- **리그·동작**: 자동 리깅(Tripo 또는 Mixamo). 동작 5개: 앉아서 타이핑, 앉아서 게임패드, 의자에 기대 쉬기, 침대에 누워 자기, 서서 기지개. GLB 하나에 2MB 이하.
- **자리**: PC 도우미의 분류와 시간을 따른다.
  - 코딩·공부·디자인: 메인 방 책상에서 타이핑
  - 게임: 책상에서 게임패드
  - 영상·쉬는 중: 영화방 소파
  - 밤 늦게 신호가 없으면 침실에서 자기
- **말풍선**: 지금은 책상 위 고정 위치에 뜬다. 캐릭터 머리 뼈를 따라가도록 바꾼다.

## 8. 이벤트 (3단계 끝)

3~8분마다 하나씩, 시간·날씨 조건이 맞을 때만 일어난다. 모션 줄이기 설정이면 일어나지 않는다.

| 이벤트 | 조건 | 모습 |
|---|---|---|
| 고양이 | 언제나 | 메인 방 문으로 들어와 빈백에 앉음 (모델 1개, 동작 2개) |
| 별똥별 | 맑은 밤 | 창밖으로 긴 빛줄기 |
| 비가 그침 | 비 → 흐림으로 바뀔 때 | 빗줄기가 줄고 창에 물방울이 남음 |
| 노크 | 방명록에 새 글 | 문이 살짝 빛나며 똑똑 소리, 누르면 방명록 |

## 9. 무게와 품질 단계

- 처음에는 지금 방의 모델만 불러오고, 옆방 모델은 쉬는 시간에 미리 불러온다.
- 화질 설정에 따라 다르게 보여준다.

| 화질 | 보여주는 것 |
|---|---|
| 낮게 | 모델 대신 대체 모양 유지 (모바일에서 가볍게) |
| 보통 | 모델, 그림자 없음 |
| 높게 | 모델, 그림자와 높은 해상도 |

- 목표:
  - 첫 방 로딩: 3D 코드 0.2MB + 모델 5MB 이하
  - 속도: 보통 화질에서 노트북 60fps
  - 모바일: 낮은 화질로 30fps 이상
