# INTERACTION DESIGN

> 상태: PHASE 1 구현 기준 + 이후 가설.

## 1. 방 둘러보기 (구현)

| 입력 | 동작 |
|---|---|
| 마우스 드래그 / 한 손가락 드래그 | 방 가운데(책상 쪽)를 중심으로 회전. 손을 떼도 감쇠하며 멈춤 |
| 휠 / 핀치 | 확대·축소 (0.6~1.75m) |
| 패닝 | 꺼 둠. 좁은 방에서 길을 잃기 쉬움 |
| "방 전체 보기" 버튼 | 처음 시점으로 부드럽게 이동 |

제한: 위아래 각도 31°~96°(천장/바닥 정면을 보지 않음), 카메라 위치는 벽·옷장·모니터 앞 상자 안.

## 2. 사물 (구현: 3개)

| 사물 | 호버 | 클릭 | 포커스 시점 |
|---|---|---|---|
| 왼쪽 모니터 | 주황 테두리, 이름표 "왼쪽 모니터 / 게임 아카이브", 화면이 켜짐 | 모니터 정면으로 다가감 → GAME ARCHIVE | 모니터 앞 약 1m |
| 오른쪽 모니터 | 같음 | → CYBERSECURITY KNOWLEDGE LAB | 같음 |
| 포스터 (3장 묶음) | 같음 | 포스터 벽 정면 → CINEMA ARCHIVE | 벽 앞 약 1.5m |

- 클릭과 드래그 구분: 누른 뒤 6px 넘게 움직이면 클릭이 아님.
- 커서: 사물 위에서 손가락.
- 선택 중(다가가는 중/보는 중)에는 Orbit과 호버를 끈다.
- 콘텐츠를 보는 중 아래 바로가기 버튼으로 다른 사물을 고르면 방으로 돌아가지 않고 바로 그 사물로 옮겨 간다.

## 3. 진입과 복귀 (구현)

1. 클릭 → 카메라가 가감속 곡선으로 사물 앞까지 이동(0.55~1.3초).
2. 도착 → 패널이 열림. 넓은 화면은 오른쪽 패널, 좁은 화면(<900px)은 아래 시트.
3. 넓은 화면에서는 장면을 왼쪽으로 밀어 사물이 패널 왼쪽에 보이게 함.
4. 복귀: "← 방으로 돌아가기" 버튼, ESC, 브라우저 뒤로 가기(주소 # 변경). 카메라는 클릭 직전 시점으로 돌아감.
5. 주소에 `#monitor-left`처럼 열린 사물을 적음 → 새로고침·링크 공유 시 같은 사물로 다시 들어감. 없는 ID는 무시.

## 4. 접근성 (구현)

- 아래 "사물 바로가기" 버튼: 3D를 조작하지 않고도 모든 사물에 들어감(키보드 Tab/Enter).
- 패널이 열리면 "돌아가기" 버튼에 포커스.
- `prefers-reduced-motion: reduce` → 카메라 즉시 이동, 패널 애니메이션 끔.
- WebGL이 없으면 목록형 화면(같은 패널).
- 상단 안내 문구는 `aria-live="polite"`로 상태 변화를 알림.

## 5. 사물별 진입 연출 (가설, PHASE 2 이후 비교)

| 사물 | 후보 A | 후보 B |
|---|---|---|
| 모니터 | 화면 평면이 화면 전체로 커지며 앱 UI로 전환 | 지금처럼 패널 (가벼움) |
| 포스터 | 포스터 한 장씩 앞으로 떨어져 나와 카드처럼 넘김 | 벽 정면 + 패널 |
| 소설책 | 책장이 펼쳐지며 세계관 노트 | |
| 큐브 | 큐브가 빛나고 회전하며 게임 화면 | |
| 카드 | 카드 셔플 → 테이블 시점 | |
| 헤드셋 | 미니 플레이어가 화면 구석에 고정 | |
| 스크린 | 방 조명 어두워짐 → 스크린 확대 → 상영 모드 | |

결정 기준: 3초 안에 콘텐츠 도달, 375px에서도 읽힘, 모션 감소 대체 경로가 있음.

## 6. 오프닝 (계획, PHASE 2)

어두운 화면 → 창으로 빛 → 책상·모니터·포스터를 스치는 카메라 → 방 전체 시점에서 정지 → 바로 조작 가능.
- 우선 **복원된 3D 방 안에서 카메라 경로를 직접 렌더**하는 방식. 끝 프레임과 조작 시작 시점이 같아 끊김이 없다.
- Runway 영상 + 프레임 시퀀스는 실제 방 구조를 지키는지 검증된 경우에만. (이 세션에서 Runway 연결은 로그인 만료 상태라 쓰지 않았다.)
- 오프닝 자산과 3D 방을 동시에 무겁게 불러오지 않는다. 건너뛰기 버튼 필수.
