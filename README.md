# 0zong의 방

취미와 공부를 전부 모아둔 방 하나를 스크롤로 둘러보는 개인 사이트입니다.
스크롤하면 카메라가 방 안의 물체를 하나씩 비추고, 아래쪽 아이콘 바로 원하는 물체에 바로 갈 수 있어요.

## 실행

처음 한 번, 주인 계정을 만듭니다:

```bash
cp .env.example .env.local
npm run hash-password -- "내 비밀번호"   # 출력된 두 줄을 .env.local에 붙여넣기
```

`OWNER_NAME`(기본 `0zong`)을 방명록 이름 칸에 입력하면 비밀번호 칸이 나타나고, 맞으면 편집 모드가 켜집니다.

```bash
npm install
npm run dev        # http://localhost:3000
```

타입 검사와 배포용 빌드:

```bash
npx tsc --noEmit
npm run build && npm start
```

## 구조

| 파일 | 하는 일 |
|---|---|
| `app/components/ScrollHero.tsx` | 캔버스 + JPEG 프레임 스크럽. 스크롤 진행도 하나로 프레임과 모든 텍스트를 함께 움직입니다. |
| `app/components/IconBar.tsx` | 화면 아래 고정 아이콘 바. 누르면 카메라가 그 물체로 날아갑니다. |
| `app/components/HeroContext.tsx` | 히어로의 스크롤 진행도를 아이콘 바와 공유합니다. |
| `app/data.ts` | 방 목록(이름, 설명, 아이콘, 최근 소식), `FRAME_COUNT`, 물체별 정지 지점 `MARKS`. |
| `app/components/*Section.tsx` | 히어로가 끝난 뒤 이어지는 소개, 방 목록, 최근 기록, 마무리 섹션. |
| `public/frames/` | 스크럽에 쓰는 프레임 (`frame_0001.jpg` …). |

캔버스는 프레임이 실제로 로드된 경우에만 "그린 프레임"으로 기록합니다. 그래서 첫 로드에서
프레임이 늦게 도착해도 빈 화면으로 남지 않아요. 텍스트는 이미지 로딩과 상관없이 스크롤 진행도만 따릅니다.

## 지금의 프레임에 대해

현재 `public/frames/`의 202장은 직접 만든 방 이미지 한 장을 카메라 투어 경로대로 잘라서 렌더링한 것입니다.
Runway 유료 플랜에서 방 안을 날아다니는 영상을 만들면 그 영상으로 바꿀 수 있어요.

### Runway 영상으로 바꾸기

1. Runway에서 방 이미지를 시작 프레임으로 영상을 만듭니다(예: seedance-2, 16:9, 1080p).
   투어 순서대로 카메라가 지나가도록 프롬프트를 씁니다:
   턴테이블 → 프로젝터 → 소파 → 모니터 두 대 → 포커 테이블 → 이젤 → 위스키 선반 → 체스판 → 스크린.
2. 받은 영상을 프레임으로 뽑습니다:

   ```bash
   rm -f public/frames/*.jpg
   ffmpeg -i hero.mp4 -vf "fps=24,scale=1920:-1" -q:v 3 public/frames/frame_%04d.jpg
   npm run frames   # 실제 파일 개수를 출력합니다
   ```

3. 출력된 숫자를 `app/data.ts`의 `FRAME_COUNT`에 넣습니다.
4. 각 물체가 화면에 멈추는 지점이 바뀌었다면 `MARKS`(0~1 진행도)와 물체별 `rect`(프레임 안 위치)를 새 영상에 맞게 고칩니다.
5. 새 영상 해상도가 1280×720이 아니면 `ScrollHero.tsx`의 `FRAME_W`, `FRAME_H`도 바꿉니다.

## 내용 바꾸기

방 이름, 설명, 최근 소식은 모두 `app/data.ts`의 `ROOMS`에 있습니다. "요즘 이 방에서 일어난 일"의
예시 기록은 `app/components/NowSection.tsx`의 `FEED`에 있어요. 지금 들어 있는 기록은 전부 예시입니다.

## 방명록과 방문 기록

- 처음 들어오면 방이 어두웠다가 불이 켜지고, 이름을 남길지 묻습니다. **들어가기**(이름), **익명으로**, **그냥 둘러볼게요** 중 고를 수 있어요.
- 이름이나 익명을 고른 방문자만 기록합니다: 들어옴, 소개 카드를 1.2초 이상 본 방, 아이콘 바 클릭, 열어본 방, 방명록 작성.
  **IP, 기기 정보, 위치는 저장하지 않아요.** "그냥 둘러볼게요"를 고르면 아무것도 보내지 않습니다.
- 방명록 글은 누구나 볼 수 있고, 방문 기록은 주인만 봅니다(아이콘 바의 막대그래프 버튼, 또는 `/admin`).
- 주인은 방 카드를 열어 소개·최근 소식을 고칠 수 있고, 방명록 글을 숨길 수 있어요.

### 데이터 저장 위치

기본은 `data/db.json` 파일 하나입니다(`lib/store.ts`). 내 컴퓨터나 서버 한 대에서 돌릴 때는 충분해요.
Vercel 같은 서버리스에 올리면 파일이 유지되지 않으니, 그때는 `lib/store.ts`의 함수들만 Supabase/Postgres로 바꾸면 됩니다.
API 라우트는 이 파일의 함수만 호출해요.

## 미리보기용 정적 빌드

`npm run export-preview`는 서버 없이 도는 복사본을 `out/`에 만듭니다. 이 빌드는 **데모 모드**라 기록이 보는 사람 브라우저에만
저장되고, 주인 비밀번호가 `demo`예요. 실제 사이트로 배포하지 마세요.
