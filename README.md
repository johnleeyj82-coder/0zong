# 0zong의 방

취미와 공부를 전부 모아둔 작은 3D 집(메인 방 · 영화방 · 침실)을 둘러보는 개인 사이트입니다.
스크롤은 없어요. 끌어서 방을 둘러보고, 물건을 누르면 그 취미의 기록이, 문을 누르면 옆방이 나와요.
침실 침대에서는 집 안의 시간을 바꿀 수 있고(내 화면에서만), 평소에는 서울의 실제 시간과 날씨를 따라가요.

## 실행

처음 한 번, 주인 계정을 만듭니다:

```bash
cp .env.example .env.local
npm run hash-password -- "내 비밀번호"   # 출력된 두 줄을 .env.local에 붙여넣기
```

`OWNER_NAME`(기본 `0zong`)을 방명록 이름 칸에 입력하면 비밀번호 칸이 나타나고, 맞으면 편집 모드가 켜집니다.

```bash
npm install
npm run dev        # http://localhost:3000
```

타입 검사와 배포용 빌드:

```bash
npx tsc --noEmit
npm run build && npm start
```

## 구조

| 파일 | 하는 일 |
|---|---|
| `app/scene/spaces/<id>.ts` | 방 하나의 정의: 크기, 벽·바닥 색, 창, 물건(대체 모양 또는 나중의 GLB), 문, 램프, 카메라 시작 위치. |
| `app/scene/House.tsx` | three.js 장면(react-three-fiber). `/`에서만, 브라우저에서만 불러와요. |
| `app/scene/look.ts` | 시간대 × 날씨 → 하늘·햇빛·램프·창밖 도시 불빛. |
| `app/components/SceneContext.tsx` | 지금 있는 방(`/?room=`), 고른 물건, 화질, 서울 시간·날씨, 침대로 바꾼 시간. |
| `app/components/SpaceBar.tsx` | 왼쪽 위: 방 이동 탭, 서울 시각·날씨, 보기 설정(화질, 주인은 날씨 고정). |
| `app/components/Caption.tsx` | 고른 물건의 카드(카메라는 움직이지 않아요). 침대는 시간 고르기 카드. |
| `app/components/IconBar.tsx` | 화면 아래 독. 취미가 방별로 묶여 있고, 다른 방 물건을 누르면 그 방으로 옮겨가요. |
| `app/data.ts` | 취미 목록(`ROOMS`: 이름, 설명, 아이콘, 최근 소식, 놓인 방)과 방 목록(`SPACES`). |
| `lib/env.ts`, `app/api/env` | Open-Meteo 서울 날씨(30분 캐시), 시간대 계산, 주인의 날씨 고정. |

3D가 안 되는 기기거나 화질을 "끄기"로 두면 방 사진 한 장과 독으로 똑같이 둘러볼 수 있어요.

## 내용 바꾸기

취미 이름, 설명, 최근 소식은 `app/data.ts`의 `ROOMS`에 있습니다. 물건의 자리와 모양은 `app/scene/spaces/`에 있어요.
"요즘 이 집에서 일어난 일"의 예시 기록은 `app/components/Panels.tsx`의 `FEED`에 있어요. 지금 들어 있는 기록은 전부 예시입니다.

## PC 도우미와 오늘의 방

내 Windows PC에서 지금 뭘 하는지(코딩·게임·디자인·공부·영상·쉬는 중)를 방에 보여주는 작은 스크립트예요.

1. 편집 모드에서 독의 막대그래프 버튼 → **PC 도우미** → "도우미 연결하기". 토큰은 그때 한 번만 보여요.
2. "도우미 받기 (.ps1)"로 `0zong-helper.ps1`을 받아요(파일은 `public/tools/`에 있어요).
3. 화면에 나온 한 줄을 Windows PowerShell에 붙여넣어요. 창을 닫으면 멈춰요.

- 30초마다 맨 앞 창의 **프로그램 이름만** 보고 분류해요. 창 제목·문서 내용·화면은 읽지 않아요.
- 목록에 없는 프로그램(브라우저 포함)과 5분 이상 입력이 없을 때는 아무것도 보내지 않아요. 목록은 스크립트 맨 위 `$Apps`에서 고쳐요.
- 구경꾼은 분류별 시간만 봐요. "구경꾼에게 지금 하는 일 보여주기"를 켜면 메인 방 책상 위 말풍선에 분류가 3분 늦게 떠요.
- 새 토큰을 만들면 예전 토큰은 바로 막혀요. 서버에는 토큰의 해시만 저장해요.

독의 **오늘의 방**에서 오늘과 최근 7일 분류별 시간, 그리고 게임·영화·음악 방의 최근 기록을 볼 수 있어요.

## 방명록과 방문 기록

- 처음 들어오면 방이 어두웠다가 불이 켜지고, 이름을 남길지 묻습니다. **들어가기**(이름), **익명으로**, **그냥 둘러볼게요** 중 고를 수 있어요.
- 이름이나 익명을 고른 방문자만 기록합니다: 들어옴, 물건 카드를 1.2초 이상 본 취미, 독 클릭, 열어본 취미, 방 이동, 방명록 작성.
  **IP, 기기 정보, 위치는 저장하지 않아요.** "그냥 둘러볼게요"를 고르면 아무것도 보내지 않습니다.
- 방명록 글은 누구나 볼 수 있고, 방문 기록은 주인만 봅니다(독의 막대그래프 버튼, 또는 `/admin`).
- 주인은 취미 서랍을 열어 소개·최근 소식을 고칠 수 있고, 방명록 글을 숨길 수 있어요.

### 데이터 저장 위치

기본은 `data/db.json` 파일 하나입니다(`lib/store.ts`). 내 컴퓨터나 서버 한 대에서 돌릴 때는 충분해요.
Vercel 같은 서버리스에 올리면 파일이 유지되지 않으니, 그때는 `lib/store.ts`의 함수들만 Supabase/Postgres로 바꾸면 됩니다.
API 라우트는 이 파일의 함수만 호출해요.

## 미리보기용 정적 빌드

`npm run export-preview`는 서버 없이 도는 복사본을 `out/`에 만듭니다. 이 빌드는 **데모 모드**라 기록이 보는 사람 브라우저에만
저장되고, 주인 비밀번호가 `demo`예요. 실제 사이트로 배포하지 마세요.
