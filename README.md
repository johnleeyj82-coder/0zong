# 0zong의 방

의자 자리에서 찍은 360도 실사 사진 위에 클릭할 수 있는 물건을 얹은 개인 포트폴리오 사이트.

## 실행

```bash
npm install
npm run dev
```

## 방 사진 찍기 (휴대폰)

의자에 앉은 자리에서 휴대폰을 눈높이에 두고, 몸을 조금씩 돌리며 사진끼리 3분의 1쯤 겹치게 찍는다.

- 정면 높이로 한 바퀴 12장
- 위로 45도 기울여 한 바퀴 8장
- 아래로 45도 기울여 한 바퀴 8장
- 천장 1장, 바닥 1장

휴대폰은 렌즈 위치를 거의 그대로 두고 그 자리에서 돌린다. 줌은 1배, 노출은 한 바퀴 내내 고정하면 이음새가 덜 보인다.
시간대마다(아침, 낮, 노을, 밤, 밤에 불 켠 것) 같은 자리에서 한 세트씩 찍는다.

## 사진을 360도 사진으로 붙이기

Hugin 명령줄 도구가 필요하다 (`apt-get install hugin-tools enblend`, 파이썬 `opencv-python-headless`).

```bash
tools/stitch.sh 사진폴더/ public/pano/noon.jpg
```

천장·바닥처럼 무늬가 없어 비는 곳은 `tools/fill_poles.py`가 주변 색으로 메운다.
첫 번째 사진이 바라본 방향이 360도 사진의 가운데(yaw 0)가 된다.

## 사진 넣기

`src/room/config.ts`의 `panos`에 시간과 파일을 적는다. 시간 슬라이더에 맞춰 가까운 두 장이 부드럽게 섞인다.
`lamp`를 적은 사진은 **조명** 버튼을 켰을 때 그 사진으로 바뀐다.

## 물건 위치 잡기

1. 화면 아래 **배치 모드**를 켠다. 물건 자리가 파란 테두리로 보인다.
2. 사진에서 물건의 가운데를 클릭하면 `yaw`, `pitch`가 나온다. 양 끝을 클릭하면 가로·세로 각도도 알 수 있다.
3. 그 값을 `src/room/config.ts`의 `hotspots`에 넣는다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/room/config.ts` | 시작 방향, 시간대별 사진, 물건 목록과 각도 |
| `src/room/PanoSphere.tsx` | 360도 사진을 구에 입히고, 시간대·조명 사진을 섞기 |
| `src/room/CameraRig.tsx` | 드래그로 둘러보기, 휠 확대, 물건 쪽으로 돌아보며 확대 |
| `src/room/Hotspots.tsx` | 호버 테두리·이름표, 클릭 선택 |
| `src/room/time.ts` | 시간에 따라 섞을 사진 고르기 |
| `tools/stitch.sh` | 사진 여러 장 → 360도 사진 |

`public/pano/sample-*.jpg`는 실제 사진이 오기 전까지 쓰는 임시 사진이다(이전 조립식 3D 방을 렌더링한 것).
